- Your devices now find each other through Nostr relays first, with Tawny's own service as the backup, so pairing no longer depends on one server.
- Servers: use your own relays, see which ones work, or use only your relays.
- Security: an expired pairing code, or an old QR code, can no longer be used to connect.
